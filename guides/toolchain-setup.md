# Настройка инструментов сборки

## JDK

Нужен JDK, подходящий ядру и версии. На машине есть:

- JDK 17 — для Forge 1.20.1 и старше
- JDK 21 — для NeoForge 1.21.x
- JDK 25 — для актуального Fabric Loom 1.19.x

Переключение — через переменную `JAVA_HOME` перед запуском Gradle.

## Gradle

Проекты используют Gradle. Варианты:

- Wrapper (`gradlew`) — сам скачает нужную версию по `gradle-wrapper.properties`.
- Локальная установка — быстрее, если версия уже есть:
  `C:\Users\satda\Desktop\Modding\.tools\gradle-<версия>`

Полезные флаги:

- `--no-daemon` — не оставлять фоновый процесс (меньше нагрузки на ПК)
- `--console=plain` — читаемый вывод без прогресс-баров
- `--offline` — переиспользовать кэш, если интернета нет

## Кэш

- Gradle-кэш: `C:\Users\satda\.gradle\caches`
- Повторная сборка с тем же набором версий идёт заметно быстрее.
