## Где смотреть версии Minecraft и Java

- Android/Java требования — Minecraft Wiki, страница версии.
- Класс-файлы Java: JDK 8 → 52, JDK 11 → 55, JDK 17 → 61, JDK 21 → 65.
- Соответствие: MC 1.21.x → JDK 21; MC 1.19.4–1.20.4 → JDK 17; MC 1.16.5 → JDK 8/11.
