# JSON UI в Bedrock Edition

JSON UI — это система описания интерфейса в файлах пака ресурсов.
Позволяет менять внешний вид экранов игры и создавать собственные.

> Источники (официальные):
> - Схемы UI: `https://github.com/MicrosoftDocs/minecraft-creator`
>   - `content/forms/ui/ui_screen.form.json` — файл экрана.
>   - `content/forms/ui/ui_element.form.json` — свойства элементов.
>   - `content/forms/ui/ui_defs.form.json` — реестр UI-файлов.
>   - `content/forms/ui/ui_global_variables.form.json` — глобальные переменные.

## Где лежат UI-файлы

- В паке ресурсов, обычно в папке `resource_pack/ui/`.
- Имена файлов — произвольные `*.json`.
- Обязателен файл-реестр `resource_pack/ui/_ui_defs.json`.

## Файл `_ui_defs.json`

Официальная структура (`ui_defs`):

- Корневой ключ — `ui_defs`.
- Значение — массив путей к UI-файлам.
- Пути относительно корня пака ресурсов, обычно начинаются с `ui/`.

Пример:

```json
{
  "ui_defs": [
    "ui/my_screen.json",
    "ui/my_common_elements.json"
  ]
}
```

Без этого файла игра не загрузит ваши UI-файлы.

## Структура файла экрана

Официальная схема (`ui_screen`) описывает:

- `namespace` — пространство имён. Необязательно. Внутри него элементы
  ссылаются друг на друга как `namespace.element`.
- Все остальные ключи — определения элементов.
- Имя элемента может содержать наследование: `my_button@common.button`.
- Переменные элемента начинаются с `$`.

Пример файла `ui/my_screen.json`:

```json
{
  "namespace": "my_ui",

  "my_title": {
    "type": "label",
    "text": "Заголовок",
    "color": [1, 1, 1]
  },

  "my_button@common.button": {
    "size": ["120px", "20px"],
    "controls": [
      {
        "label": {
          "type": "label",
          "text": "Нажми"
        }
      }
    ]
  },

  "my_screen": {
    "type": "panel",
    "size": ["100%", "100%"],
    "controls": [
      { "title@my_ui.my_title": {} },
      { "btn@my_ui.my_button": {} }
    ]
  }
}
```

Разбор:

- `namespace: "my_ui"` — все элементы доступны как `my_ui.имя`.
- `my_button@common.button` — наследует базовую кнопку `common.button`.
- `controls` — вложенные элементы (массив объектов).
- `size` — `["ширина", "высота"]`.

## Наследование и переменные

- Запись `имя@базовый` означает «взять элемент `базовый` и изменить».
- Базовые элементы берите из официальных UI-файлов ванильного пака
  ресурсов (`Mojang/bedrock-samples`, папка `resource_pack/ui/`), например
  `common.button`, `common.dialog_background`.
- Переменные (`$имя`) задают параметры элемента и могут переопределяться
  при наследовании.

Пример переопределения переменной:

```json
{
  "my_wide_button@common.button": {
    "$button_text": "Широкая кнопка",
    "size": ["200px", "20px"]
  }
}
```

## Типы UI-элементов

Официальный список типов:

- `panel` — контейнер.
- `stack_panel` — стопка (элементы идут друг за другом).
- `image` — картинка.
- `label` — текст.
- `button` — кнопка.
- `toggle` — переключатель.
- `slider` — ползунок.
- `slider_box` — ползунок с числовым полем.
- `edit_box` — поле ввода текста.
- `grid` — сетка.
- `scroll_view` — область с прокруткой.
- `scrollbar_box` — полоса прокрутки.
- `dropdown` — выпадающий список.
- `input_panel` — панель ввода.
- `screen` — экран.
- `custom` — свой элемент (с полем `renderer`).
- `factory` — фабрика (динамическая генерация элементов).
- `selection_wheel` — колесо выбора.

## Основные свойства элемента

Официальные поля (`ui_element`):

- `type` — тип элемента.
- `size` — размер `[ширина, высота]`.
- `offset` — смещение от позиции якоря.
- `anchor_from`, `anchor_to` — точки привязки.
- `layer` — порядок отрисовки.
- `controls` — вложенные элементы.
- `renderer` — рендерер для типа `custom`.
- `$переменная` — собственные переменные.

## Единицы измерения

- `px` — пиксели: `"20px"`.
- `%` — проценты от родителя: `"50%"`.
- `%c` — проценты от размера экрана (client): `"100%c"`.
- `%cm` — проценты с учётом масштаба интерфейса.
- `default` — размер по умолчанию для элемента.

## Привязка (anchor)

- `anchor_from` — точка на самом элементе.
- `anchor_to` — точка на родителе, к которой привязывается элемент.
- Значения: `top_left`, `top_middle`, `top_right`, `left_middle`,
  `center`, `right_middle`, `bottom_left`, `bottom_middle`,
  `bottom_right`.

Пример центрирования:

```json
{
  "centered_panel": {
    "type": "panel",
    "size": ["200px", "100px"],
    "anchor_from": "center",
    "anchor_to": "center"
  }
}
```

## Глобальные переменные

- Файл `ui_global_variables` задаёт переменные, доступные во всех UI-файлах.
- Полезно для общей цветовой схемы, размеров, повторно используемых имён.

## Как переопределить существующий экран игры

- В своём UI-файле объявите элемент с **именем ванильного экрана**
  (например, `inventory_screen`) — он перекроет стандартный.
- Так меняют вид инвентаря, чата, HUD.
- **Осторожно:** переопределение чужого экрана ломается при обновлении
  игры — ванильные имена могут меняться.

Пример изменения фона инвентаря:

```json
{
  "namespace": "my_ui",
  "inventory_screen@common.base_screen": {
    "background_control": {
      "type": "image",
      "texture": "textures/ui/my_background"
    }
  }
}
```

## HUD (экран поверх игры)

- `hud_screen` — корневой HUD.
- Пользовательские элементы HUD добавляют как дочерние к `hud_screen`.
- Для данных из скриптов используют привязки (binding) к переменным, а не
  жёсткий текст.

## Связь JSON UI и скриптов

- JSON UI сам по себе статичен.
- Для изменения UI из скриптов используют «bindings» — официальный механизм
  привязки свойств экрана к данным.
- В новых версиях появляется `CustomForm` в `@minecraft/server-ui` —
  «data-driven UI» (DDUI), где форму строят из кода без написания JSON UI.

## Когда JSON UI не нужен

- Для простых меню (кнопки, вопросы, анкеты) берите `@minecraft/server-ui`.
- JSON UI оправдан для: HUD, графических панелей, изменения вида ванильных
  экранов, полностью нестандартных интерфейсов.

## Частые ошибки

- **Не создан `_ui_defs.json`** — файлы игнорируются.
- **Наследование от несуществующего элемента** — экран не загрузится.
  Базовые элементы берите из ванильного пака ресурсов.
- **Неверные единицы** (`"20"` вместо `"20px"`) — размер не применится.
- **Опечатка в `anchor_from`/`anchor_to`** — элемент уедет за экран.
- **Переопределение ванильного экрана** — ломается между версиями, готовьте
  к обслуживанию.
- **Путь в `_ui_defs.json` без `ui/`** — файл не найдётся.

## Порядок работы

1. Создать `_ui_defs.json` с путями к своим файлам.
2. Создать UI-файлы в `resource_pack/ui/`.
3. Взять базовые элементы из ванильных UI-файлов (в этом же папке).
4. Собрать экран из `panel`/`stack_panel` + `label`/`button`/`image`.
5. Проверить в игре, включив журнал содержимого.
