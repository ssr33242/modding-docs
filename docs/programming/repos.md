> Правило: это репозитории **самих проектов** (организация-владелец языка или
> инструмента), а не сторонние подборки — кроме отмеченных разделов

## Как этим пользоваться

- Исходники проекта — лучший источник правды о поведении API.
- Ищите примеры в папках `examples/`, `docs/`, `tests/`.
- Для API сверяйтесь с официальным сайтом проекта, а не с блогами.
- Версии и совместимость проверяйте в `CHANGELOG`/`releases`, а не по памяти.

## Частые ошибки

- **Брать сторонний туториал вместо официальных исходников** — код
  устаревает.
- **Копировать код без проверки лицензии** — учитывайте лицензию проекта.
- **Считать, что у всех репозиториев одинаковый стиль** — структура разная.
- **Не проверять версию** — примеры для старой версии могут не работать.
