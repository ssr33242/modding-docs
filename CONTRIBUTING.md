# Как contribute

Справочник открыт для дополнений. Главное правило: **факты — из первоисточников,
версии — из живых API, утверждения — проверяемые.**

## Что можно делать

- Добавлять и править гайды в `docs/` и `guides/`.
- Добавлять шаблоны в `templates/`.
- Обновлять версии в `COMPATIBILITY.md`, `versions.json` и `docs/java/versions.md`.
- Присылать разборы ошибок сборки в `docs/java/unsupported.md` — это самый
  ценный раздел.

## Как обновить версии

Версии живут в трёх местах, и все три обновляются автоматически:

```bash
python scripts/refresh_versions.py          # обновить versions.json
python scripts/refresh_versions.py --check  # только посмотреть
```

Скрипт тянет данные из официальных API (Mojang, Fabric meta, Modrinth, NeoForge,
Forge, Quilt, PaperMC) и пишет их в `versions.json`. CI запускает его ежедневно
(`.github/workflows/refresh-versions.yml`) и сам коммитит изменения.

Если ты обновил версию вручную — упомяни это в коммите, чтобы было видно
источник.

## Правила содержания

1. **Не выдумывать версии.** Каждая версия должна браться из живого источника;
   в коммите или в `versions.json` указывай, откуда.
2. **Разделяй «проверено сборкой» и «по документации».** В `COMPATIBILITY.md`
   строки «проверено сборкой» означают, что jar реально собран **и** содержит
   `.class`-файлы.
3. **Указывай дату проверки** для данных, которые устаревают (версии).
4. **Не ломай структуру.** Файлы в `docs/` — тематические справочники, в
   `guides/` — пошаговые инструкции, в `templates/` — готовые проекты.
5. **Ссылки — на первоисточники.** Не на пересказы.

## Формат коммитов

Коротко и по делу, в стиле репозитория:

```
docs: версии загрузчиков на 21.10.2026
docs: гайд по миграции 1.21.x → 26.x
fix: Fabric поддерживает 26.x (маппинги Mojang)
templates: fabric 26.3 — обновлён под mojmap
```

## Проверка перед отправкой

```bash
python scripts/refresh_versions.py --check   # источники живы
python -c "import json;json.load(open('versions.json',encoding='utf-8'))"
```

Сборка сайта (если менял `docs/`):

```bash
pip install mkdocs-material
mkdocs build
```

## Куда смотреть за контекстом

- `knowledge/knowledge-map.md` — карта репозитория, начни с неё.
- `COMPATIBILITY.md` — что с чем собирается.
- `docs/java/unsupported.md` — почему что-то не собирается.
